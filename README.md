## Projects

### JobReady AI
**AI-powered recruitment assistant** — *In Progress*

Analyzes resumes, extracts structured data, and generates candidate insights using the Gemini API. The goal is to cut down manual screening time for recruiters by surfacing the most relevant information automatically.

What's working so far:
- Resume parsing and structured data extraction
- Skill and experience analysis through Gemini API
- AI-generated candidate summaries
- Backend candidate data management with MongoDB

What I'm still building:
- Candidate scoring and ranking system
- Recruiter-facing dashboard
- Prompt optimization for sharper AI output

**Built with:** Node.js, Express, MongoDB, Gemini API

---

### College Bus Tracking System
**Real-time location tracking for college buses**

Built to solve an actual problem at my college — students never knew where the bus was. Now they can see it moving on a live map.

- Live location updates via Socket.io
- Interactive map with moving markers using Leaflet.js
- Driver login with Passport.js authentication
- Session management with MongoDB

**Built with:** Node.js, Express, MongoDB, Socket.io, Leaflet.js, Tailwind CSS

[View Live](https://advance-bus-tracking-deployment.onrender.com/)

### Diary
**A social writing platform**

A full-stack app where users write and share stories. Includes authentication, full CRUD, likes, comments, follows, and real-time updates. Server-rendered with EJS in a clean, distraction-free interface.

- Secure auth with hashed passwords and sessions
- Create, edit, delete stories
- Like, comment, and follow system
- Real-time interactions via Socket.io

**Built with:** Node.js, Express, MongoDB, EJS, Socket.io, Tailwind CSS

[View Live](https://diary-web-app-nine.vercel.app/stories)
