## 🚌 Real-Time College Bus Tracking System

</summary>

A full-stack real-time bus tracking platform that enables students to track college buses live while allowing drivers to securely share their GPS location. The system provides accurate ETA predictions, route visualization, and live journey updates to improve daily campus transportation.

### Key Features

- Live GPS location tracking
- Real-time updates using Socket.IO
- ETA calculation
- Route visualization with Leaflet.js
- Driver & Student dashboards
- Speed, stoppage, and delay monitoring
- Responsive UI built with Tailwind CSS
- Structured MVC backend architecture
- Production deployment on Render

### Impact

- Reduced average location refresh time from **~10 seconds** to **under 2 seconds**
- Built scalable real-time communication using WebSockets

### Tech Stack

React • Node.js • Express • MongoDB • Socket.IO • Leaflet.js • TypeScript

**Live Demo**
